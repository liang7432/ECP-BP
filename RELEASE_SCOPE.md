# Release scope

This is a data-only release containing the non-confidential computational inputs and result records cited in the manuscript and supplementary material.

Included:

- exact and held-out benchmark inputs;
- public-network-derived inputs;
- structural factorial inputs;
- stochastic consistency-check inputs;
- equivalence-profile diagnostic inputs;
- compact result exports and final validation summaries;
- file-integrity metadata.

Excluded:

- private operational and enterprise records;
- source calibration panels and identifying fields;
- raw run directories, logs, traces, and route-level output;
- software and execution scripts;
- internal project and working documents.

The corresponding author remains responsible for confirming data ownership, redistribution rights, and any institutional or commercial restrictions before publication.
